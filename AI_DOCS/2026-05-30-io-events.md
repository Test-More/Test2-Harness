# IOEvents: in-subtest STDOUT/STDERR as Test2 events

## Task

Prints and warnings made inside a subtest landed loose at the top level of the
event log (raw `from_stream` lines carry no nesting), so they rendered after the
subtest instead of inside it. Goal: optionally turn in-subtest prints/warnings
into Test2 `info` events that fold into the subtest at the correct nesting.

Triggered by: user request, following the Part A assembler fix (see below).

## Design

On by default; disabled per test job via env, or pinned via a collector
attribute.

- `Test2::Formatter::Stream2::IOEvents` — installer. `enable` registers a
  `pre_subtest` callback that lazily ties `STDOUT`/`STDERR` on the first subtest
  entry. Nothing touches the I/O layer until a subtest actually runs.
- `Test2::Formatter::Stream2::IOEvents::Tie` — tie handler. `PRINT`/`PRINTF`
  convert to a `context()->send_ev2_and_release(info => [...])` event (tag
  STDOUT/STDERR, `debug => 1` for STDERR) **only** when `_should_convert` is
  true: a subtest is open (`test2_stack->top->nested > 0`), Test2 is loaded,
  `${^GLOBAL_PHASE} eq 'RUN'`, the pid is unchanged, and no conversion is
  already in progress (reentrancy latch). Otherwise the print passes through to
  a dup of the real handle.

Toggle: `Test2::Formatter::Stream2::init` calls `IOEvents->enable` **unless**
`T2_HARNESS2_IO_EVENTS` is set to a false value (`0`/empty) — i.e. on by
default. The collector's `io_events` attribute, when set, pins the child env
(`1` forces on, `0` forces off); left unset, the child keeps its default (on).

## Decisions / alternatives

- **Tie, not PerlIO.** A prior PerlIO-layer attempt segfaulted; tie is the
  proven mechanism (mirrors the standalone `Test2::Plugin::IOEvents`).
- **Convert in all subtests (buffered, streamed, legacy), not buffered-only.**
  The conversion routes through `context()`, so nesting is authoritative for
  every Test2 subtest shape. TAP subtests get nothing (they are not Test2 in the
  child) — an accepted limitation.
- **Lazy install via `pre_subtest`, never uninstalled.** There is no symmetric
  `post_subtest` hook, and an always-passthrough tie outside subtests is
  harmless. This also keeps `context()` away from the top level, where it is
  unsafe during cascading warnings/exceptions or before Test2 init.
- **No origin marker on the events.** The Part A assembler fix
  (`fix(collector): suppress all nested subtest events, not just structural`)
  makes nesting alone drive the stray/fold duality, so a converted print is just
  a nested `info` event and needs no marker to get the right treatment.
- **Only whole lines convert, tracked per handle.** A print with no trailing
  newline is a partial line and passes through to the real handle. The handle
  then stays in passthrough for every following print -- including the one that
  finally ends the line -- until the line completes, so a partial line is never
  split between the raw stream and an event. Conversion resumes on the next
  newline-terminated print. This `pending` state is per handle (a partial on
  STDERR does not affect STDOUT), so progress bars / column-at-a-time output do
  not fragment into events.
- **Ties are refreshed on every subtest start.** The `pre_subtest` callback
  re-runs `_install_ties`, which re-ties any handle whose tie an intervening
  reopen dropped (e.g. `Capture::Tiny`, explicit `open STDOUT, ...`), while
  leaving a still-live tie (ours or another module's) alone.
- **Full filehandle proxy** (`WRITE`, `BINMODE`, `OPEN`, `CLOSE`, `FILENO`,
  `autoflush` + a dup of the real fd) so `fileno`/`-t`/`syswrite`/reopen behave
  like a real handle and legacy tests are not broken. `WRITE` (syswrite) is
  always passthrough, never converted.
- **No recursion; fork/exec safe.** The Stream2 `EventEmitter` holds its pipe
  via `Atomic::Pipe->from_fh('>&=', ...)` (a raw fd), so its writes bypass the
  tied glob. `exec` replaces the process (tie is Perl-only); a plain fork trips
  the pid guard and passes through, so forked/exec'd output reaches the real
  handle unconverted.

## Scope of change

- New: `lib/Test2/Formatter/Stream2/IOEvents.pm`,
  `lib/Test2/Formatter/Stream2/IOEvents/Tie.pm`.
- `Test2::Formatter::Stream2::init` — enable when the env var is set.
- `Test2::Harness2::Collector` — new `io_events` attribute; sets the child env.
- Tests: unit (`Tie`, `IOEvents`), integration (`io_events.t`).

Known gaps (inherent, not bugs): TAP subtests; and raw output from forked or
`exec`'d children that never load the tie.
